//operators
An operator is a symbol or keyword that performs an operation on one or more values.
Example:
+ adds values.
- subtracts values.
* multiplies values.
== checks whether two values are equal.
&& checks whether two conditions are true.
//Expression
An expression is a combination of values, variables, operators, and sometimes function calls that produces a result.
Example:
let result = 10 + 5
print(result)

Output:15
//Compound assignment operators
These perform a calculation and update the existing variable.
Operator	Equivalent expression
+=	a = a + b
-=	a = a - b
*=	a = a * b
/=	a = a / b
//Nil-coalescing operator — ??
Provides a default value when an optional value is nil.
Example:
let name: String? = nil
let displayName = name ?? "Guest"
print(displayName)

//Ternary operator — ? :
A short form of choosing between two values based on a condition.
Example:
let marks = 80
let result = marks >= 50 ? "Pass" : "Fail"
print(result)
